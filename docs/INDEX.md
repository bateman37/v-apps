# Índice documental

Este índice es el punto de entrada a toda la documentación de Vincle Apps. Los documentos están agrupados por área y ordenados según un orden de lectura recomendado para una sesión que empieza desde cero.

## Orden de lectura recomendado

1. [`PROJECT_STATUS.md`](PROJECT_STATUS.md) — estado actual del proyecto y próxima entrega.
2. [`product/VISION.md`](product/VISION.md) — qué es Vincle Apps y qué módulos incorporará.
3. [`product/SCOPE.md`](product/SCOPE.md) — qué está en alcance y qué está fuera de alcance ahora mismo.
4. [`product/ROADMAP.md`](product/ROADMAP.md) — fases de alto nivel, sin fechas.
5. [`architecture/ARCHITECTURE.md`](architecture/ARCHITECTURE.md) — arquitectura inicial propuesta y principios técnicos.
6. [`architecture/DATA_MODEL.md`](architecture/DATA_MODEL.md) — modelo conceptual de entidades y relaciones.
7. [`architecture/SECURITY.md`](architecture/SECURITY.md) — reglas de seguridad y datos sensibles.
8. [`design/BRAND_UI.md`](design/BRAND_UI.md) — identidad visual de Vincle aplicada a la interfaz: tokens de color, tipografía y accesibilidad.
9. [`shared/MASTER_DATA.md`](shared/MASTER_DATA.md) — maestros compartidos por toda la plataforma.
10. [`offers/OVERVIEW.md`](offers/OVERVIEW.md) — visión funcional del Gestor de Ofertas.
11. [`offers/FIELDS.md`](offers/FIELDS.md) — campos del formulario de oferta.
12. [`offers/BUSINESS_RULES.md`](offers/BUSINESS_RULES.md) — numeración, jornadas y reglas de negocio conocidas.
13. [`offers/STATUSES.md`](offers/STATUSES.md) — estados de oferta conocidos.
14. [`offers/MIGRATION.md`](offers/MIGRATION.md) — estrategia de migración desde SQL Server / Excel.
15. [`decisions/DECISIONS.md`](decisions/DECISIONS.md) — registro de decisiones aprobadas y pendientes.

## Documentación de proceso (raíz del repositorio)

- [`../AGENTS.md`](../AGENTS.md) — reglas canónicas de colaboración para cualquier agente.
- [`../CLAUDE.md`](../CLAUDE.md) — instrucciones específicas para Claude Code.
- [`../CHANGELOG.md`](../CHANGELOG.md) — historial de entregas.
- [`../prompts/README.md`](../prompts/README.md) — convención de conservación de encargos.

## Convenciones de este índice

- Cada regla o decisión tiene una única ubicación canónica; los demás documentos la enlazan en lugar de repetirla.
- Las etiquetas `APROBADO`, `PENDIENTE`, `PLANIFICADO` e `IMPLEMENTADO` se usan de forma consistente en toda la documentación para indicar el estado de una decisión o funcionalidad. Su significado se define en [`decisions/DECISIONS.md`](decisions/DECISIONS.md).
